AlgoQuant tutorials and application examples

Learn the library by following data loading, strategy construction, simulation, performance measurement and export calls. Model Javadoc distinguishes the original publication from the parameters and assumptions used by each tutorial.

  • Tutorial reading guide and demo catalog
  • Original publications, review scope and implementation differences
  • Known example limitations
  • Runnable source and setup instructions
  • AlgoQuant library API reference

Start with SMA2Demo010 for simulator assembly, then TutorialStrategy for event handling and Infantino2010ParamAnalysisDemo for a research-model sensitivity study. The six technical demos use synthetic inputs by default. Other examples may need market downloads, local datasets, desktop charts, database configuration or broker services.

The examples are educational adaptations; a citation does not mean a paper's complete method, dataset or empirical results have been reproduced. A valid external NM license is required to execute the library; it is not needed to read these pages.
